# ApplyOnce Privacy Policy

**Last updated:** October 24, 2026

## Overview

ApplyOnce is a browser extension designed to help users fill job application forms and track job applications. It is designed to operate locally in the browser.

## Information Stored

ApplyOnce may store information that users choose to enter, including:
- Professional profile details, such as name, email, phone number, education, and professional links.
- Job application records, such as company, job title, application status, URL, dates, and notes.
- User preferences and custom profile fields.

## How Information Is Used

The information is used to match saved profile details to relevant form fields when the user requests a scan, fill selected fields, and maintain the user's application tracker.

## Local Storage and Data Sharing

ApplyOnce is designed to store profile and application information in browser-local storage. The extension does not intentionally transmit this information to an external server or sell or share it with advertisers.

The extension is designed not to use remote AI services or send user data to external AI providers.

## Webpage Access

When the user invokes the scanning or autofill feature, ApplyOnce examines relevant form fields on the current webpage to identify possible matches. Users can review suggested values before filling fields. ApplyOnce does not automatically submit job applications.

## Data Retention and Deletion

Information remains in the browser until the user deletes it or clears the extension's stored data. Users can use the extension's available data-deletion feature to remove stored profile and application records. Users can also remove the extension from their browser.

## Children's Privacy

ApplyOnce is a general productivity tool and is not designed specifically to collect information from children.

## Changes to This Policy

This policy may be updated when the extension's functionality or data practices change. The latest version will be published in this repository.

## Contact

For privacy questions or concerns, contact the repository maintainer through the [ApplyOnce GitHub repository](https://github.com/pranjal224153/applyonce).
